
RAMEN API
=========

This section provides documentation for the public APIs of RAMEN.


Ramen Class
-----------

.. class:: ramen.Ramen.Ramen

   The main RAMEN class used to perform random walk-based network
   inference and genetic algorithm-based structured learning.

   .. method:: __init__(self, csv_data="", end_string="", min_values=0)

      Constructor of the Ramen object.

      :param csv_data: Path to the data in CSV form. Mandatory.
      :type csv_data: str
      :param end_string: The destination variable of absorbing random walk.
      :type end_string: str
      :param min_values: Minimum number of values required in a column.
                         Variables below this threshold are pruned.
      :type min_values: int

   .. method:: random_walk(self, num_walks=50000, num_steps=None, p_value=0.05, correction="no_correction")

      Begin the absorbing random walk after the Ramen object is initialized.

      Significant edges are stored in
      ``ramen_object.signif_edges``.

      :param num_walks: Number of random walks per experiment.
      :type num_walks: int
      :param num_steps: Maximum steps per random walk. If None, RAMEN
                        automatically selects between 3 and 9 steps
                        according to the number of retained variables.
      :type num_steps: int or None
      :param p_value: Cutoff value used to determine significance of
                      edge visits. Default is 0.05.
      :type p_value: float
      :param correction: Correction method for significant-edge
                         p-values. Supported values are ``"fdr"``
                         and ``"no_correction"``.
      :type correction: str
      :rtype: None

   .. method:: genetic_algorithm(self, num_candidates=10, end_thresh=0.01, mutate_num=100, best_cand_num=10, bad_reprod_accept=10, reg_factor=0.01, hard_stop=100)

      Begin the genetic algorithm after the random walk is complete.

      The resulting network is stored in
      ``ramen_object.network``.

      :param num_candidates: Number of initial candidates.
      :type num_candidates: int
      :param end_thresh: Threshold for score improvement between
                         generations. Default is 0.01.
      :type end_thresh: float
      :param mutate_num: Number of mutations per intermediate candidate
                         after crossover.
      :type mutate_num: int
      :param best_cand_num: Number of top candidates retained after
                            each generation.
      :type best_cand_num: int
      :param bad_reprod_accept: Number of generations with score
                                increase below end_thresh before
                                convergence.
      :type bad_reprod_accept: int
      :param reg_factor: Score penalty per edge.
      :type reg_factor: float
      :param hard_stop: Maximum number of generations.
      :type hard_stop: int
      :rtype: None

   .. method:: export_ramen_as_dict(self)

      Export RAMEN results as a dictionary.

      The dictionary contains dataset information, significant
      random-walk edges, final network edges, edge visit counts,
      and end-variable arrival counts.

      :return: Dictionary containing RAMEN run results.
      :rtype: dict

   .. method:: get_export_report(self)

      Generate a human-readable summary report of the RAMEN run.

      The report includes the dataset path, end variable, number of
      significant edges, the first 10 significant edges, and the
      number of nodes and edges in the final network.

      :return: RAMEN run summary as a string.
      :rtype: str

   .. method:: set_end_string(self, end_string)

      Modify the end_string of the absorbing random walk.

      :param end_string: Name of the end variable.
      :type end_string: str
      :rtype: None

   .. method:: get_signif_edges(self)

      Return a copy of the significant edges.

      :return: List of tuples representing significant edges.
      :rtype: list

   .. method:: set_signif_edges(self, signif_edges)

      Set the significant edges.

      :param signif_edges: Significant edges to set.
      :type signif_edges: list
      :rtype: None

   .. method:: get_edge_visit_dict(self)

      Get the edge visit dictionary generated by the random walk.

      :return: Dictionary mapping edges to their visit counts.
      :rtype: dict

   .. method:: get_var_ref(self)

      Get the discrete-to-variable value reference.

      :return: Dictionary of variable value mappings.
      :rtype: dict

   .. method:: get_mutual_info_array(self)

      Get the mutual information matrix.

      :return: 2D array containing mutual information values.
      :rtype: numpy.array
